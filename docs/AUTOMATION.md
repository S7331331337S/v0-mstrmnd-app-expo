# MSTRMND Automation Loop

This file defines the daily automation cycle for operating MSTRMND as a product.

## Core loop

1. Run system
2. Capture output
3. Share output
4. Collect feedback
5. Improve system

---

## Daily execution

### 1. Run multi-agent system

Execute:

- runMultiAgent()

Capture:
- logs
- final output
- agent steps

---

### 2. Capture content

Turn output into:
- demo clip
- screenshot
- share page

---

### 3. Post

Use template:

"Most AI tools give you answers.\n\nMSTRMND builds with you."

---

### 4. Feedback loop

Track:
- comments
- DMs
- confusion points

---

### 5. Improve

Adjust:
- onboarding
- prompts
- agent roles

---

## Weekly automation

- Review best outputs
- Save as templates
- Create new pipelines

---

## System rule

Never stop the loop:

Run → Share → Learn → Improve
